# K Sports Fisio Pedra Branca

Projeto estático em HTML, pronto para publicação no GitHub Pages ou em hospedagens como Vercel/Netlify.

## Arquivos

- `index.html` — página completa do site. As imagens utilizadas no projeto estão incorporadas no próprio HTML, então não é necessária uma pasta `img/` separada.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório (o arquivo `index.html` deve ficar na raiz, não dentro de outra pasta).
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço indicado na seção Pages.

## Observação

O mapa incorporado utiliza o Google Maps e precisa de conexão com a internet para carregar. Links e serviços externos do site também dependem de conexão.
